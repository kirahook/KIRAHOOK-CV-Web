KIRAHOOK · PERSONAL PORTFOLIO
FILE X-001 / 星绘友晴天
STAR PARTY

设计领域：交互游戏设计
时间：原始作品集
创作者：胡鑫洋 / KIRAHOOK
访问范围：PROJECT ARCHIVE

围绕《星绘友晴天》的轻松社交与角色表达，参与拍照功能、角色与服装 GUI、游戏视觉物料及模型协作。设计把角色形象、场景与界面联系起来，让玩家在同一套视觉语言中完成装扮、自拍和分享；图版集中展示游戏 KV、角色服装与宣传视觉。

项目性质：企业实习 / 项目协作
设计重点：角色表达 / 自拍 / GUI
方法：任务流程；界面原型；视觉迭代
产出：游戏 KV、角色与服装图版、GUI 与宣传物料
原稿页码：3

背景：项目来自网易雷火 UX 实习，面对角色社交游戏中“展示自我”和“理解操作”同时发生的场景。设计需要兼顾游戏世界的活泼气质、功能可读性与制作协作。

设计说明
1. 依据原图版与 CV，工作包含功能界面原型、GUI、角色与服装、Steam 视觉及测试迭代。整理时以自拍、装扮、发布等具体任务为线索，区分界面内容、角色资产和发行物料。
2. 将明亮的色彩、圆润图形与角色表情延续到界面和 KV；在服装选择、角色展示与功能控件之间建立层级，避免视觉装饰挤占玩家当前任务。
3. 从角色与服装选择进入形象展示，再衔接自拍界面和视觉输出；原型与 GUI 对接模型、场景及游戏部署环节。海外测试与迭代属于 CV 记载的参与工作。
4. 呈现个人参与的 UX、GUI 与视觉产出；游戏整体研发及上线由项目团队完成。

说明依据原始作品集对应图版及已提供的 CV / 证明整理；图版解读与方案设想不补写未提供的研究样本、测试数据或商业成果。

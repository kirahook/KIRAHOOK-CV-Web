FILE X-003 / 赛博狂潮
CYBER SURGE

设计领域：交互游戏设计
时间：原始作品集
创作者：胡鑫洋 / KIRAHOOK
访问范围：PROJECT ARCHIVE

以赛博风格的 5v5 英雄选择为核心，构建从世界观、角色档案到备战确认的界面体系。霓虹、高对比色与卡片式人物资料共同服务于角色辨识，让玩家在浏览形象的同时理解定位、技能和数值，并明确当前选中状态。

项目性质：概念设计 / 原型方案
设计重点：英雄选择 / 状态反馈
方法：风格研究；信息层级；交互流程
产出：视觉规范、英雄档案界面、备战与加载页
原稿页码：5、6、7

背景：英雄选择既是阵容决策，也是玩家认识游戏世界的入口。方案需要在强烈的风格表达中维持角色比较、技能阅读和确认动作的清晰度。

设计说明
1. 原图版包括风格参考、色彩规范、角色信息和操作流程。围绕“看角色—比能力—作选择”整理信息，把背景叙事与影响选择的技能、定位分层处理。
2. 采用“狂野潮流”的霓虹与酸性色彩；选中角色突出显示，其他角色减弱，利用视觉状态明确当前焦点。角色档案卡承载形象、能力与背景信息。
3. 浏览英雄列表 → 选中角色并查看技能 / 数值 → 确认备战 → 进入 5v5 加载展示。状态反馈贯穿选择与确认。
4. 自主游戏交互与视觉概念方案，现有材料展示界面设计与流程，不代表已商业发行。

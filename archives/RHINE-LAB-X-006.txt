FILE X-006 / 杀戮之夜
NIGHT OF SLAUGHTER

设计领域：交互游戏设计
时间：原始作品集
创作者：胡鑫洋 / KIRAHOOK
访问范围：PROJECT ARCHIVE

为 4v1 非对称对抗场景设计匹配、角色准备、技能查看、加载与结算界面。方案以暗色氛围和角色差异强化追猎关系，同时将技能数量、冷却、效果与队友状态拆分展示，让玩家在进入对局前明确身份、能力和准备状态。

项目性质：概念设计 / 原型方案
设计重点：非对称对抗 / 准备流程
方法：角色任务拆解；状态设计；结果分组
产出：匹配与准备页、技能组件、加载与结算页
原稿页码：11、12

背景：追猎者与生存者拥有不同目标与技能配置，准备阶段的信息负担也不同。界面需要表达不对称身份，同时保持公共流程的一致性。

设计说明
1. 图版围绕随机身份、准备、倒计时和结果展开，并区分追猎者两项技能、生存者一项技能。按“身份—能力—队伍—准备”检查信息顺序。
2. 以技能图标、名称、说明、冷却和类型构成阅读单元；准备按钮与倒计时对应明确状态，结算页将积分、荣誉和奖励分组呈现。
3. 匹配 → 分配身份 → 查看技能及队友 → 准备 / 倒计时 → 加载 → 对局结果与奖励。
4. 自主非对称对抗游戏界面概念，展示设计逻辑与画面产出。

说明依据原始作品集对应图版及已提供的 CV / 证明整理；图版解读与方案设想不补写未提供的研究样本、测试数据或商业成果。

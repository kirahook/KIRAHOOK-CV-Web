FILE X-007 / Oasis · 多模态情感疗愈
OASIS

设计领域：概念设计
时间：原始作品集
创作者：胡鑫洋 / KIRAHOOK
访问范围：PROJECT ARCHIVE

Oasis 探索磁悬浮装置、光与多模态反馈如何构成日常情绪表达的媒介。项目从情绪调节的理论线索和生活压力场景出发，推进到产品形态、内部结构、灯带与交互故事板，把抽象情绪转为可感知的空间与物理变化。

项目性质：概念设计 / 原型方案
设计重点：情绪表达 / 多模态反馈
方法：理论转译；情境故事板；结构拆解
产出：产品形态、结构与 PCB 示意、交互故事板
原稿页码：14、15

背景：项目关注城市生活与后疫情情境下的情绪压力，尝试用日常可接近的装置提供感知与表达情绪的入口。

设计说明
1. 图版引入 Gross 情绪调节过程模型作为设计线索，并展示多模态情感策略、形态与交互场景。将理论概念转译为感知、表达与反馈之间的关系。
2. 磁悬浮形态、灯光与产品外壳共同承担情绪隐喻；承载结构、布线与 PCB 的拆解使外观表达和内部构成相互对应。
3. 进入使用情境 → 感知与表达情绪 → 装置给予多模态反馈 → 用户观察和调整体验。故事板用于表达情境与反馈时序。
4. 情绪体验与产品概念探索；资料未提供临床试验或疗效证据。

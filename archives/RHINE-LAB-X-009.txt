FILE X-009 / 心源 · 共生 · 未来
HEART / SYMBIOSIS / FUTURE

设计领域：概念设计
时间：原始作品集
创作者：胡鑫洋 / KIRAHOOK
访问范围：PROJECT ARCHIVE

围绕个体、群体与数字系统的共生关系，借助分形、元胞自动机、粒子和声音响应生成不断演化的视觉场景。作品将规则、输入与涌现结果联系起来，让观众从观看固定画面转向参与变化，探索秩序与混沌之间的感知体验。

项目性质：生成艺术 / 媒介实验
设计重点：生成规则 / 群体涌现
方法：分形研究；元胞自动机；声音响应
产出：生成视觉、粒子与细胞实验、多阶段体验
原稿页码：21、22、23、24、25、26、27、28、29

背景：项目从后疫情时代的数字依赖与情感反馈切入，关注个体输入如何与群体化、系统化的视觉行为发生关联。

设计说明
1. 原图版出现 Mandelbulb 分形、Conway 生命游戏、细胞状态与城市形态等线索。研究侧重生成规则、局部变化和整体涌现之间的关系。
2. 把粒子、聚合球体、分形空间等视觉阶段组织为连续体验；规则既产生秩序，也保留不可完全预测的变化，呼应共生主题。
3. 用户或声音输入 → 参数与局部状态变化 → 粒子 / 细胞演化 → 群体图形反馈。图版中的 Processing 与生成实验用于展示方法。
4. 生成艺术与多感官体验探索；情感主题属于创作动机，资料未提供心理干预效果验证。

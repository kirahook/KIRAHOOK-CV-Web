FILE X-011 / 解构音频工作站
DECONSTRUCTED AUDIO STATION

设计领域：产品设计
时间：原始作品集
创作者：胡鑫洋 / KIRAHOOK
访问范围：PROJECT ARCHIVE

解构音频工作站将 CD 播放、刻录、音量与均衡控制整合为具有复古气质的模块化桌面产品。设计以独立音乐创作和实体音频体验为背景，通过分层布局、旋钮、按键与显示反馈梳理设备关系，使数字内容的处理与物理媒介的留存形成闭环。

项目性质：概念设计 / 原型方案
设计重点：实体音频 / 模块化操作
方法：使用任务；功能拆解；结构与尺寸
产出：产品渲染、功能分区、拆解与工程表达
原稿页码：35、36、37

背景：多设备组合容易带来操作学习与桌面组织负担。项目尝试在数字音乐操作中保留实体媒介与可触控的体验。

设计说明
1. 图版围绕独立音乐人、怀旧音频与设备操作展开，展示功能拆解、结构线稿和尺寸。依据使用任务整理播放、刻录与声音调节的关联。
2. 以层叠模块区分功能区，旋钮承担连续调节，按键承载明确动作；显示与呼吸灯为工作状态提供视觉反馈。
3. 选择音源 / CD → 播放或刻录 → 调节音量与 EQ → 观察显示状态 → 获得声音输出或实体记录。
4. 工业设计概念与结构表达；图版中的功能为方案设定，未提供量产、声学性能或工程认证。

说明依据原始作品集对应图版及已提供的 CV / 证明整理；图版解读与方案设想不补写未提供的研究样本、测试数据或商业成果。

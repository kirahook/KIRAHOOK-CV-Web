FILE X-014 / 即梦 AI · Prompt 分层编辑
DREAMINA / SEEDREAM · PROMPT LAYERS

设计领域：UI/UX设计
时间：原始作品集
创作者：胡鑫洋 / KIRAHOOK
访问范围：PROJECT ARCHIVE

针对图像生成中“不知道怎样写”和“难以局部修改”的提示词问题，提出 Prompt 分层编辑方案。设计把主体、场景与动作拆解成可编辑的信息单元，将文字与图像区域对应，并结合灵感语料与生成反馈支持持续调整；相关交互方法已形成专利申请公开文件。

项目性质：概念设计 / 原型方案
设计重点：Prompt 分层 / 局部编辑
方法：竞品分析；信息拆解；Human-in-the-loop
产出：分层编辑流程、交互界面、专利申请公开文件
原稿页码：44、45、46、47、48、49、50

背景：单段提示词承载多个对象、场景和动作时，用户容易难以定位修改对象。方案关注新手学习与多轮生成中的可控性。

设计说明
1. 图版比较即梦、FLUX、Grok、Imagen 等生成产品的交互表达，并分析提示内容缺失、结构不清与修改繁琐等问题。竞品名称用于记录设计研究对象。
2. 把外观中的主体 / 对象 / 背景与动作、姿态分层，提供局部编辑和新增内容入口；用风格、场景、画质与构图语料辅助表达。
3. 输入意图 → 拆解提示单元并建立图像对应 → 局部调整 → 再次生成 → 根据结果继续编辑。用户保留对生成过程的判断与修改。
4. 2024 年即梦 AI 交互创新方案。专利申请号 202411897527.9，公布号 CN 122289430 A；文件性质为申请公开，胡鑫洋为第 4 位发明人。

FILE X-015 / Mythos · 文化智能体
MYTHOS / ETERNAL CARTOGRAPHY

设计领域：UI/UX设计
时间：原始作品集
创作者：胡鑫洋 / KIRAHOOK
访问范围：PROJECT ARCHIVE

Mythos 将文化智能体从单一问答扩展为带有时空、身份与来源线索的探索界面。方案把地图、历史时期、角色对话和证据放入同一任务中，帮助用户在不同文化位置之间比较理解，并保留追问和修正解释的空间。

项目性质：概念设计 / 原型方案
设计重点：文化情境 / 来源 / 对话
方法：情境建模；证据关联；多视图联动
产出：智能体界面、地图与时期视图、对话流程
原稿页码：51、52、53

背景：文化知识的理解依赖时间、地点与叙述者立场，孤立答案难以交代这些关系。项目关注情境、证据和探索主动性。

设计说明
1. 图版从情境缺失、证据不足与用户能动性三个方面组织问题，呈现角色、地图、时期与来源的联动结构。
2. 以一次提问串联时空定位、资料来源与角色解释；将比较与追问作为探索路径，使解释能回到具体材料和文化语境。
3. 提出问题 → 定位文化与历史情境 → 查看角色解释和来源 → 对照不同观点 → 继续追问或调整解释。
4. 文化智能体交互原型；资料未提供知识准确率、模型评测或事实核查实验结果。

说明依据原始作品集对应图版及已提供的 CV / 证明整理；图版解读与方案设想不补写未提供的研究样本、测试数据或商业成果。

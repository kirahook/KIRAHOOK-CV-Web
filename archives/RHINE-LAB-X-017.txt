FILE X-017 / Elder-Care · 适老饮食管理
ELDER-CARE UX DESIGN

设计领域：UI/UX设计
时间：原始作品集
创作者：胡鑫洋 / KIRAHOOK
访问范围：PROJECT ARCHIVE

Elder-Care 将饮食习惯、营养信息和适老操作放入同一服务流程。设计回应感官与身体机能变化，探索营养可视化、食物替代建议和摄入反馈，使用户在保留熟悉口味的同时理解饮食选择，并通过移动端与其他界面协同完成记录和查看。

项目性质：概念设计 / 原型方案
设计重点：适老饮食 / 营养可视化
方法：用户情境；任务分析；跨端原型
产出：营养报告、饮食管理界面、跨端流程
原稿页码：55、56、57、58、59

背景：老龄化背景下，嗅味觉、手部操作与吸收能力的变化会影响日常饮食；方案关注习惯延续与营养支持的平衡。

设计说明
1. 图版呈现用户与身体变化分析、饮食管理任务和 AI / AIGC 信息方案。依据痛点与界面对应关系，整理记录、监测、理解和调整的路径。
2. 将营养报告可视化，结合食物替代、摄入记录与反馈；信息按任务分组，避免把复杂营养内容一次性呈现给用户。
3. 记录 / 识别食物 → 查看营养与摄入信息 → 理解替代建议 → 调整饮食 → 回看反馈；移动端与 H5 / 桌面界面承担不同查看场景。
4. 适老饮食管理服务与界面方案。图版中的百分比为界面呈现材料，未作为临床、营养或用户测试效果引用。

说明依据原始作品集对应图版及已提供的 CV / 证明整理；图版解读与方案设想不补写未提供的研究样本、测试数据或商业成果。

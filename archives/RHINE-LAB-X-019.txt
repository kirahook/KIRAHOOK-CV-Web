FILE X-019 / 绿韵黔中 · 贵阳本土植物饮食可视化
GREEN RHYTHMS OF CENTRAL GUIZHOU

设计领域：视觉设计
时间：原始作品集
创作者：胡鑫洋 / KIRAHOOK
访问范围：PROJECT ARCHIVE

以贵阳折耳根饮食为切口，从植物、地貌、季节、菜肴、城市记忆与气味感知六个维度组织地方知识。作品把植物部位、产区与消费、烹饪方式及日常场景转成不同图形结构，使同一种食材在自然环境、饮食文化与个体感知中的联系被逐层看见。

项目性质：信息设计 / 文化可视化
设计重点：地方饮食 / 六维知识图谱
方法：材料归类；关系编码；叙事可视化
产出：植物与地貌图、菜肴分类、记忆与感知图谱
原稿页码：64、65、66、67、68、69

背景：地方食材既是植物，也是生活习惯与城市身份的载体。项目以鱼腥草 / 折耳根连接自然条件、餐桌与感官差异。

设计说明
1. 六张图版分别采用 PLANT、TERRAIN、SEASON、DISH、MEMORY、SENSE 结构，包含植物部位、气候节律、做法分类与气味分子等材料。
2. 根据内容关系选用分类树、时间节律、空间网络和感知图谱；保持跨图版的视觉语言，同时让不同维度使用适合的阅读方式。
3. 认识植物 → 理解地理与气候 → 追踪季节与供应 → 阅读菜肴做法 → 进入城市日常 → 比较气味感知。
4. 信息设计与地方文化可视化；图版数字按原稿保留，扩展说明不将其推断为新的统计调查或医学结论。

说明依据原始作品集对应图版及已提供的 CV / 证明整理；图版解读与方案设想不补写未提供的研究样本、测试数据或商业成果。

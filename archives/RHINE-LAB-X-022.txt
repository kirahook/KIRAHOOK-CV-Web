FILE X-022 / 反乌托邦 · 信息自救
DYSTOPIA / INFORMATION & RESISTANCE

设计领域：体验设计
时间：原始作品集
创作者：胡鑫洋 / KIRAHOOK
访问范围：PROJECT ARCHIVE

借《1984》与《美丽新世界》的反乌托邦线索，讨论数字生活中的监控、记忆、信息差与自我修正。作品通过摄像头、数据库、虚拟牢笼和生成系统等概念装置，把不可见的信息关系转为可观察的结构，追问个体如何理解并回应自身所处的信息环境。

项目性质：思辨设计 / 信息议题
设计重点：信息权力 / 监控 / 自我修正
方法：文本线索；隐私议题；装置隐喻
产出：议题与关系图、概念装置、生成视觉
原稿页码：83、84、85、86、87、88、89、90

背景：数字系统收集、保存与组织个人信息，也影响人们看见什么与如何判断。项目将信息权力关系转为思辨设计议题。

设计说明
1. 图版把信息茧房、拥有记忆的数据库、加剧信息差的虚拟牢笼及未知风险下的自我修正组织为连续讨论，并参考隐私与数据保护概念。
2. 以摄像头阵列、存储 / 中继结构和生命式生成图形构建隐喻，让监控、传播和选择在装置语言中具象化。
3. 识别信息收集 → 观察记忆与关联 → 感受信息边界 → 思考反馈与自我修正 → 回到个体的信息自救。
4. 批判性与思辨性作品；图版中的隐私规范为研究背景，扩展文字不作为法律建议或系统安全保证。

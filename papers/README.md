# Paper PDFs

Place user-approved public PDFs here after they are provided. In `content/papers.json`, set the corresponding paper's `pdf` to `papers/<filename>.pdf`. Keep unpublished or anonymous review drafts out of this directory unless Hu Xinyang explicitly selects that version.

The existing reader supports previous/next pages, numeric page jump, width fit, zoom and horizontal touch swipes. All PDF fields are currently `null`, as requested on 2026-10-14.
